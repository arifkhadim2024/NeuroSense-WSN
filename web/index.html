Scientific Purpose & Analytical Interpretation Feature Extraction for Sleep Scheduling
1. Multiplicity Heatmap (Output: k-Coverage & Redundancy Index)
Evaluates discrete 1.0m grid points across the 100m × 100m field. Points covered by ≥ 2 sensors (Emerald / Amber) represent redundant sensing capacity where sensor nodes can be put to SLEEP to conserve battery without creating coverage holes.
2. Bounded Voronoi Tessellation (Output: Territorial Area Feature A_i)
Computes each sensor's convex polygon partition bounded to [0, 100]². Voronoi cell area (A_i) is fed directly into the ANN Multi-Layer Perceptron. Nodes with small interior cells and high overlap are scheduled to sleep, while boundary/large-cell nodes remain active.

Scientific Purpose: Why Use an Artificial Neural Network in WSNs? Decentralized O(1) Inference vs NP-Hard Greedy Optimization
1. The Computational Bottleneck in WSN Sleep Scheduling
Finding the optimal subset of sensor nodes to put to sleep while guaranteeing 100% field coverage is an NP-hard Set Cover problem. The exact Greedy Oracle takes ~69.17 ms per scheduling cycle in Python, which is too computationally expensive and battery-draining to run on low-power embedded microcontrollers in real time.
2. The Neural Multi-Layer Perceptron (8 → 16 → 8 → 1)
The ANN is trained offline on oracle decisions using 8 spatial and energy features ($E_{res}, d_{sink}, k_{nbr}, CR_{uniq}, OR, \rho_{loc}, d_{act}, obs$). Online forward pass executes in only ~8.28 ms (8.4× speedup) with 79.8% accuracy and an F1-Score of 0.8034, paired with a deterministic Coverage Guard safety net.

Theoretical Formulation & Mathematical Models

Mathematical proofs, radio dissipation equations, coverage formulations, and worked numerical examples.

First-Order Radio Energy Model

Energy dissipation for transmitting a k-bit packet across Euclidean distance d:

E_tx(k, d) = k · E_elec + (d < d0 ? k · ε_fs · d² : k · ε_mp · d⁴)
Parameters: E_elec = 50 nJ/bit, ε_fs = 10 pJ/bit/m², ε_mp = 0.0013 pJ/bit/m⁴.
Crossover threshold: d0 = sqrt(ε_fs / ε_mp) = 87.7m.
Worked Example: Transmitting k=4000 bits at d=20m (d < d0):
E_tx = 4000 × 50×10⁻⁹ + 4000 × 10×10⁻¹² × (20)² = 0.000200 + 0.000016 = 0.216 mJ.
Multi-Objective PSO Fitness Function

Evaluates optimal Cluster Head candidates balancing energy and latency:

min Fitness = w_E·(1 - E_avg/E0) + w_BS·(d_BS/d_max) + w_intra·(d_intra/d_max)
Weights: w_E = 0.35, w_BS = 0.25, w_intra = 0.20, w_cov = 0.10, w_ov = 0.10.
Worked Example: If candidate CHs have E_avg=0.45J (E0=0.5J), d_BS=60m (max=180m), d_intra=20m:
Fitness = 0.35×(1 - 0.90) + 0.25×(0.33) + 0.20×(0.11) = 0.035 + 0.083 + 0.022 = 0.140.
