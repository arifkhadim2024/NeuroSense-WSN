# NeuroSense-WSN v2 Architecture & Data Flow Specification

## 1. System Overview

NeuroSense-WSN v2 is designed with a strict separation of concerns:
- **Scientific Backend (Python)**: Executes spatial node deployment, first-order radio physics, 8-feature extraction, greedy oracle optimization, MLPClassifier neural network training/inference, and multi-hop routing simulation.
- **Presentation Workbench (Vanilla ES6 JavaScript)**: Visualizes the 3D topology with Three.js, renders 2D multiplicity heatmaps and bounded Voronoi diagrams on Canvas, renders real synaptic weights in the ANN Lab, and charts live lifecycle telemetry using Chart.js.

## 2. Mathematical Formulations

### First-Order Radio Model
The energy dissipated by transmitting a $k$-bit data packet over distance $d$ is:
$$E_{tx}(k, d) = \begin{cases} k \cdot E_{elec} + k \cdot \varepsilon_{fs} \cdot d^2, & \text{if } d < d_0 \\ k \cdot E_{elec} + k \cdot \varepsilon_{mp} \cdot d^4, & \text{if } d \ge d_0 \end{cases}$$
Where $d_0 = \sqrt{\frac{\varepsilon_{fs}}{\varepsilon_{mp}}} = \sqrt{\frac{10 \times 10^{-12}}{0.0013 \times 10^{-12}}} \approx 87.7\text{ m}$.

### 8-Feature Vector
1. **Residual Energy Ratio**: $E / E_{init}$
2. **Sink Distance**: Normalized Euclidean distance to Base Station $(50, 150)$.
3. **Neighbor Count**: Alive nodes within communication radius $R_c = 2 R_s$.
4. **Unique Coverage Ratio**: Points exclusively covered by this node.
5. **Overlap Ratio**: Points covered by this node that overlap with other nodes.
6. **Local Node Density**: Neighbor count per unit area.
7. **Nearest Active Neighbor Distance**: Proximity to nearest active peer.
8. **Obstacle Blocked Ratio**: Fraction of sensing disk obstructed by obstacles.

## 3. Scientific Limitations & Boundaries

1. **Simulation Abstraction**: Uses Heinzelman's first-order radio propagation equations with free-space and multipath thresholds rather than physical RF hardware transceiver measurements.
2. **Greedy Oracle Ground Truth**: Training labels are generated by an analytical coverage-preserving greedy oracle heuristic rather than empirical field deployment ground truth.
3. **Static Topology**: Sensor nodes maintain fixed $(x, y)$ coordinates once deployed (static WSN rather than mobile ad-hoc VANET/MANET).
4. **Single-Sink Architecture**: Assumes one static Base Station at $(50, 150)$ outside the $100\text{m} \times 100\text{m}$ sensing field.
5. **Tested Parameter Ranges**: Evaluated for $N \in [30, 150]$ nodes and sensing radius $R_s \in [8\text{m}, 30\text{m}]$.
